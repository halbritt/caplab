The division split the vocabulary along an ownership cut that is correct for durability but that no loader knew how to re-join at drive time.\n\n## Why it is delivery, not a decision\n\nThe catalog model (RFC 0001/0005) fixes what the vocabulary *means* — a target-state is a versioned predicate over the artifact graph; a pass is a versioned transformation contract — but it never fixed the vocabulary's on-disk *arity*. A catalog assembled from a base directory plus overlay directories is the same catalog, with the same semantics, as one assembled from a single directory. Overlaying changes how the loader reads the vocabulary off disk; it changes nothing about the vocabulary. So this closes the gap by delivery under P2/N11 — no RFC clause is amended, no new durable concept is introduced.\n\nThe composition is not arbitrary. D0011.C1 makes the core graph another graph's pinned environment: the shipped compiler product *is* the fleet repository's environment.
