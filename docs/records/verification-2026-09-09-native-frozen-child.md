## Decision and preparation authorization

used together in a native capture. The existing close diagnostic authenticates
the Node launcher before release, but derives the child PID from the trace and
uses a literal child configuration. Select prospective source preparation,
retain the authenticated launcher's proc directory descriptor, and observe its
actual child at the first validated WebSocket response request, before sending
any scripted response. This adds a measured pause to this diagnostic's native
configuration. It does not establish an uninstrumented execution condition.
