# Bounded claim-interpretation experiment

Under ADR 0026 and the active reviewer-ranking goal, the primary agent selects
an experiment on interpreting what reviews assert. Empirical case truth stays
outside this interpreter. This addresses the study's scoring-validity gate;
it cannot itself rank reviewers or establish whether a reported bug is real.

Authorize one native Codex CLI 0.153.4 `codex-terra-max` invocation, enforced
through `native-agent-systems.json`, with a 300-second process limit and a
single 10-second namespace/version preflight. Use the established sealed
external access-token projection and credential-private-text/v3 capture guard;
no refresh token is exposed or changed. User configuration, rules, apps,
plugins and skill search are disabled. Pin the native vendor package and
preserve actual invocation, final output and native rollout. Stop on expired
credential, input drift, capture quarantine or deadline; do not replay a
consumed invocation. Expiry: consumption or 2026-09-11T00:00:00Z.

Authorize a private copy of the exact `output-probe-3/capture/final-message.txt`
under `reviewer-ranking-001/development/claim-interpretation-1`, after verifying
its hash against the existing completed-output receipt. This final review and
newly authored adversarial review variants may be sent to the configured
native provider as experimental inputs. No original repository trees,
credentials, private runtime logs or answer keys may enter the task mount.
Preserve the old native output and all prior custody unchanged. This effect
does not register historical evidence or admit it to a comparative study.

Before execution, freeze the input documents, neutral hypothesis descriptions,
expected assertion/polarity mappings, exact-text quotation checks and the
criteria for preserving unmapped claims. The subject sees only the review
texts, hypotheses and output contract; it sees neither expected mappings nor
empirical truth labels. Include assertion, negation, retraction, uncertainty,
keyword lists, duplicates, wrong locations, unknown findings and instructions
embedded in quoted review data. Do not force unknown findings into the listed
hypotheses. Synthetic variants calibrate this interpreter only; they are not
review tasks or evidence of reviewer defect-finding quality.

No product scorer is accepted by this experiment. One actual review and a
small authored challenge set can expose failures but cannot establish broad
semantic accuracy. Model interpretation remains an inference; verified case
behavior, requirement violation, change attribution, severity and ranking
policy remain separate. In particular, quoting words is necessary for
attribution but cannot by itself prove semantic fidelity.
