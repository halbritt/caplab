# The mounting gradient decomposed: it was mostly the tree

- Date: 2026-08-23. The experiment the wrong-universe finding called for:
  both gemini arms re-measured on seed 20260819 under full isolation
  (checkouts masked, neutral cwd, preamble v2).

## Result

| | pre-isolation | post-isolation | Δ |
|---|---|---|---|
| agy harness catch | 0.842 | 0.596 | −24.6 pts |
| agy structural | 28/33 | 17/33 | −11 cells |
| agy reference classes | 7/9 | 3/9 | −4 |
| agy FA | 0.158 | 0.088 | −7 pts |
| lane catch | 0.554 | 0.500 | −5.4 pts |
| lane reference classes | 3/9 | 3/9 | 0 |
| mounting pair | 16–0, p<0.0001 | 5–0, p=0.0625 | |

The lane is the internal control: it never had filesystem access, so its
−5 prices the preamble-and-noise component, leaving roughly **20 of the
harness's 25-point drop attributable to losing ambient tree access**. The
mounting effect proper — tools in a neutral universe — is ~+9 points,
directionally persistent (5–0; still zero reversals across every pair
ever run), not established at n=56. The FA drop says part of the
harness's "over-refusal" was wrong-universe reference refusal.

## What this means, and does not mean

It does NOT mean the pre-isolation agentic numbers measured nothing:
production review lanes receive a materialized **pinned base** in their
bundles, so repo-grounded verification is part of the production task.
But they received the **live tree** — sometimes the right content,
sometimes not, never the pinned custody — and the isolated condition
gives **no** tree, which is poorer than the production affordance. Both
conditions bracket the ecologically valid one. The instrument's next
environment version should materialize the task's *pinned base* into the
workspace: bundle-faithful affordance, the correct universe by
construction.

## The comparability question this opens (Principal's)

The isolated runs derived claims under the same instrument string as the
pre-isolation cohort. Because claim identity does not yet carry the
execution-environment version, `most-comparable` selection will prefer
these newer claims by recency and silently mix environments inside the
20260819 cohort — the v1-changeset lesson at the environment level. The
clean fix is an environment field in claim identity (and the instrument
string), splitting cohorts honestly; the cheap fix is treating isolated
runs as the new canon and re-measuring the cohort's top under isolation.
Neither is CAPLAB's to pick alone.
