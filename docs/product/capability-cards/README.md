# CAPLAB capability cards

This directory preserves versioned measurement contracts reviewed for Agent
Capability Lab studies. A capability card names a construct, population,
observables, controls, scoring, rivals, exclusions, human-owned judgments, and
promotion gates. It does not itself record a capability inference.

Card files retain the exact review bytes selected or declined by the decision
owner. Their frontmatter therefore records the artifact state at review time;
the current disposition comes from the linked decision record. A selected card
does not authorize evidence admission, implementation, model calls, placement,
training, export, verification, or CAPLAB acceptance.
