# Artifact-rater launch custody

Select the actual artifact-rater version helper and scoring roots for future
explicit enrollment. Package its existing script as a public CLI first, with
unchanged unenrolled behavior; add admission in a dependent source change.
Use the existing native assigned-right supervisor and Quartermaster interval /
reconciliation SDK, with a separate artifact configuration and custody identity.
No resource arithmetic or second authoritative ledger belongs in this adapter.

Retain the rater's exact Codex argv, model/effort, prompt, schema, JSONL and final
message derivation, rollout custody, append-only attempts and publication checks.
Its native argv variant is precisely the existing long-option artifact command,
not Revbench's short-option command. Validate that complete variant separately;
do not weaken the general catalog/Revbench command matcher. The selected catalog
native tuple must still be admitted by the pinned closed native policy. This
administration is different from an existing qualified Binding.

Every helper and attempt uses a one-shot assignment in the output custody root.
A lost local publication projects the original retained native outcome; it never
creates a replacement for an uncertain consumed right. A completed failed native
attempt retains the existing rater's retry behavior: any subsequent numbered
attempt needs its own fresh permit and is subject to the finite shared budget.
This supplies no chain-completion guarantee. An enrolled root cannot be reopened
without its enrollment, and historical unenrolled output cannot be enrolled.

Add a PID namespace and explicit-byte exec gate around the original native CLI.
Retain host filesystem reads and network access; mount the output tree and native
Codex home writable, but overmount shared-launch custody read-only. Use a scrubbed
outer environment and declared HOME/CODEX_HOME/PATH, not inherited secret values.
This is process administration, not an additional scientific sandbox qualification.
The rater continues to request Codex's own read-only sandbox. Positive outer
creation counts even if exec fails. Constructor uncertainty holds both resources;
positive precreation refusal may retire the unused closed right. Parent death
cannot substitute for positive retained namespace closure. EOF cannot exec the
application. Retain full-precision same-boot clock brackets and source pins.

Under ADR0026 authorize this isolated source slice, real local-process/private-SDK
controls, public configuration documentation and an offline source-pinned wheel.
Record the exact tested commit before integration/install. Preserve active native
pins and old releases, historical captures and scientific qualification. No live
provider/model call, production-home write, account authentication, evidence
registration, campaign reopening or scientific acceptance is selected here.
Missing eligible native policy/catalog selections remain explicit; local/operator
account mappings are valid declarations, not authenticated provider observations.
Stop on unexplained custody, accounting, provenance or test failures; retain the
raw receipts and select concrete corrections before proceeding. Other producers
remain residual scope, not covered by this wrapper.
